OpenSRE provides a decoupled Python API that allows developers to instantiate, configure, and drive agent turns programmatically from Python applications, web services, or custom scripts without relying on the interactive terminal surface.

The public host API is `AgentSession` (`core.agent_harness.harness`). Every surface (shell, gateway, web, CLI, embedder) interacts with the agent runtime through `AgentSession`.

## Core Concepts

| Class / Entry Point | Import Path | Description |
| --- | --- | --- |
| `AgentSession` | `core.agent_harness.harness` | Public host API for session startup, chat turns, multi-step goal loops, and investigations. |
| `SessionConfig` | `core.agent_harness.harness` | Configuration object specifying environment loading, integration hydration, and session options. |
| `HeadlessAgent` | `core.agent_harness.turns.headless_dispatch` | Programmatic agent driver that executes turns headlessly using provided port adapters. |
| `configure_process` | `bootstrap.process` | Shared process boot utility to initialize environment, telemetry, and adapters for embedded runs. |

## Quick Start: In-Memory Headless Dispatch

To execute a single turn programmatically using default in-memory adapters and a custom reasoning client:

```python
from core.agent_harness.harness import AgentSession, SessionConfig
from core.agent_harness.turns.headless_dispatch import (
    HeadlessAgent,
    NullToolProvider,
    StaticReasoningClientProvider,
)

class CustomReasoningClient:
    def invoke_stream(self, prompt: str):
        yield "OpenSRE investigation complete: All systems normal."

# 1. Initialize AgentSession
session = AgentSession(SessionConfig(load_env=False))
session.startup()

# 2. Attach a headless agent dispatcher with custom reasoning provider
session.attach_agent(
    HeadlessAgent(
        tools=NullToolProvider(),
        session=session.session,
        reasoning=StaticReasoningClientProvider(client=CustomReasoningClient()),
    )
)

# 3. Dispatch a chat turn programmatically
result = session.chat("Check system health status")
print(result.primary_response_text)
# → "OpenSRE investigation complete: All systems normal."
```

## Session Lifecycle and Process Boot

For embedded applications or production integrations where process environment and integrations need to be booted:

```python
from bootstrap.process import EMBEDDED_PROFILE, configure_process
from core.agent_harness.harness import AgentSession, SessionConfig
from core.agent_harness.turns.headless_dispatch import (
    HeadlessAgent,
    NullToolProvider,
    StaticReasoningClientProvider,
)

class CustomReasoningClient:
    def invoke_stream(self, prompt: str):
        yield "OpenSRE investigation result: payment-gateway latency is 45ms."

# 1. Boot process environment with EMBEDDED_PROFILE
configure_process(EMBEDDED_PROFILE)

# 2. Start an AgentSession
session = AgentSession.start(
    SessionConfig(
        load_env=True,
        hydrate_integrations=True,
        warm_integrations=False,
    )
)

# 3. Attach headless agent driver
session.attach_agent(
    HeadlessAgent(
        tools=NullToolProvider(),
        session=session.session,
        reasoning=StaticReasoningClientProvider(client=CustomReasoningClient()),
    )
)

# 4. Programmatically run chat turns across the session
turn_result = session.chat("Investigate latency spike on payment-gateway service")

if turn_result.answered:
    print(f"Agent Output: {turn_result.primary_response_text}")
```

## Running Multi-Turn Goal Loops (`chat_until_goal`)

`AgentSession.chat_until_goal` executes `session.chat()` repeatedly in a loop until an outer `SessionGoal` completes or reaches its turn ceiling:

```python
from bootstrap.process import EMBEDDED_PROFILE, configure_process
from core.agent_harness.harness import AgentSession, SessionConfig
from core.agent_harness.turns.headless_dispatch import (
    HeadlessAgent,
    NullToolProvider,
    StaticReasoningClientProvider,
)

class GoalReasoningClient:
    def invoke_stream(self, prompt: str):
        yield "Goal step executed successfully."

# 1. Boot process and start session
configure_process(EMBEDDED_PROFILE)
session = AgentSession.start(SessionConfig(load_env=True))

# 2. Attach headless dispatcher
session.attach_agent(
    HeadlessAgent(
        tools=NullToolProvider(),
        session=session.session,
        reasoning=StaticReasoningClientProvider(client=GoalReasoningClient()),
    )
)

# 3. Run chat_until_goal to execute until multi-step goal completion
goal_result = session.chat_until_goal("Audit all active production alert rules")

print("Goal status:", goal_result.status)
print("Turns executed:", len(goal_result.history))
```

## Result Inspection

`session.chat()` returns a `TurnResult` dataclass containing detailed metadata about the executed turn:

```python
result = session.chat("Analyze error rates in auth-service")

# Inspect turn outcome
if result.answered:
    print("Turn answered successfully.")
    print("Response:", result.primary_response_text)
elif result.cancelled:
    print("Turn execution was cancelled.")

# Access action-phase execution metadata
action_res = result.action_result
print(f"Actions planned: {action_res.planned_count}, executed: {action_res.executed_count}")
```
